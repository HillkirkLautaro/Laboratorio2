# Laboratorio 2 – Modelos de Clasificación (Grupo 27)

Trabajo práctico de la materia **ELEMENTOS DE APRENDIZAJE DE MÁQUINA Y BIG DATA-TU TECNOLOGÍAS DE PROGRAMACION**  
Tecnicatura Universitaria en Programación – Universidad Provincial del Sudoeste (UPSO)

## Descripción
En este laboratorio se entrenan y comparan distintos modelos de clasificación
sobre un conjunto de datos, evaluando su rendimiento con métricas estándar.

## Contenido del repositorio
| Archivo | Descripción |
|---|---|
| `Modelos_Clasificación_Grupo_27.ipynb` | Notebook con la carga de datos, preprocesamiento, entrenamiento y evaluación de los modelos. |
| `README.md` | Este archivo. |
| `.gitignore` | Archivos que Git no debe subir (datos, claves, archivos generados). |

## Cómo ejecutarlo
1. Abrir el notebook en Google Colab o Jupyter Notebook.
2. Ejecutar las celdas en orden (Entorno de ejecución → Ejecutar todas).

## Tecnologías
- Python
- Jupyter Notebook / Google Colab
- pandas, scikit-learn, matplotlib
